# Дневник сна — как установить на iPhone

Приложение готово и лежит в папке **`app`** (файлы `index.html`, `manifest.webmanifest`,
`sw.js` и папка `icons`). Это веб-приложение (PWA): после установки оно выглядит и работает
как обычное приложение с иконкой, работает без интернета, а все записи хранятся **только
на вашем iPhone**. В App Store ничего публиковать не нужно.

Что умеет (версия 1.0):
- три отметки одним нажатием: **«Начали укладывать» → «Уснул» → «Проснулся»**;
- автоматический расчёт по логике вашего Excel-дневника: время бодрствования (ВБ) перед
  каждым сном, сколько длилось укладывание, длительность каждого сна, ночной сон,
  ночные пробуждения, суммарное ВБ и суммарный дневной сон за сутки;
- статистика по дням (7/14/30 дней) — построчно, как в Excel;
- 3 или 4 дневных сна — не важно, всё считается автоматически (дневным считается сон,
  начавшийся до 17:30, ночным — после);
- правка любой записи вручную + добавление пропущенных записей;
- экспорт/импорт резервной копии файлом.

## Шаг 1. Разместить приложение в интернете (один раз, ~10 минут)

Приложению нужен адрес в интернете, чтобы открыться на телефоне. Подойдёт бесплатный
GitHub Pages. По этому адресу лежит только «пустая» программа — ваши записи туда
не отправляются и никуда не уходят.

1. Зайдите на **github.com** и зарегистрируйтесь (бесплатно), если аккаунта нет.
2. Нажмите зелёную кнопку **New repository** (или «+» в правом верхнем углу → New repository).
3. Придумайте имя, например `sleep-diary`. Оставьте галочку **Public**. Нажмите **Create repository**.
4. На открывшейся странице в разделе **«…or push an existing repository»** ничего делать не надо —
   вместо этого нажмите ссылку **uploading an existing file**.
5. Откроется окно загрузки. Зайдите в папку `app` на компьютере и перетащите в окно
   **ВСЕ** файлы из неё: `index.html`, `manifest.webmanifest`, `sw.js` и папку `icons`
   (можно перетащить папку целиком).
6. Дождитесь, пока файлы появятся в списке, и нажмите зелёную кнопку **Commit changes**.
7. Теперь включите сайт: вверху репозитория вкладка **Settings** → слева пункт **Pages** →
   в разделе «Build and deployment» выберите **Source: Deploy from a branch**, ветка **main**,
   папка **/(root)** → **Save**.
8. Подождите 1–2 минуты и обновите страницу — сверху появится адрес вида
   `https://ВАШ_ЛОГИН.github.io/sleep-diary/`. Это адрес приложения.

## Шаг 2. Установить на iPhone (1 минута)

1. Откройте полученный адрес в **Safari** на iPhone (обязательно Safari, не Chrome).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) внизу экрана.
3. Пролистайте список и выберите **«На экран “Домой”»**.
4. Нажмите **Добавить**.

На рабочем столе появится иконка «Дневник сна». Приложение открывается на весь экран,
работает без интернета. Можно перенести иконку на главный экран поближе.

## Шаг 3. Резервные копии (важно!)

Записи хранятся внутри приложения на телефоне. Если удалить приложение с экрана «Домой»
или очистить в настройках данные сайтов Safari — записи пропадут. Поэтому раз в неделю-две:

- откройте приложение → вкладка **Ещё** → **Экспортировать данные (файл)**;
- файл-копия сохранится в «Файлы» (или откроется меню «Поделиться» — отправьте файл
  сами себе в Telegram/на почту);
- при необходимости восстановления: **Ещё → Импортировать из файла** и выберите копию.

## Частые вопросы

**Обновление приложения.** Если приложение дорабатывается, новые файлы просто загружаются
в тот же репозиторий GitHub (шаг 1.5–6). iPhone подхватит обновление при следующем открытии
(иногда нужно закрыть приложение из «шторки» и открыть заново).

**Посмотреть на компьютере.** В папке `app` выполните `python -m http.server 8161` и откройте
`http://localhost:8161` в браузере — но данные в телефоне и на компьютере не синхронизируются.

**Приватность.** Все записи — только в памяти телефона. Интернет нужен лишь чтобы один раз
установить приложение. Ни аккаунтов, ни отправки данных куда-либо нет.

**Ночная классификация.** Сон, начавшийся после 17:30, считается ночным. Если ребёнок лёг
днём позже 17:30 (редкий длинный «четвёртый» сон), откройте запись и переключите тип
на «Дневной» вручную.
